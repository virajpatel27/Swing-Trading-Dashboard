# Swing Trading Dashboard

Indian markets (all NSE + BSE indices, Nifty 500 stocks) for swing traders: daily prices since 2007, corporate-action-adjusted,
indicators, screener. Free: GitHub (code + data), GitHub Actions (daily update), GitHub Pages (website).

> **Educational purpose only, not investment advice.**
> This repository and its website are **public**. Only public market data is stored here - never passwords, keys or tokens.

**Live dashboard: https://virajpatel27.github.io/Swing-Trading-Dashboard/**

Status: under construction (Phase 6 of 8 done; daily automatic update comes in Phase 7). Plan: [docs/PLAN.md](docs/PLAN.md). Data sources: [docs/SOURCES.md](docs/SOURCES.md).
